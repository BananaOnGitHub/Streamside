# Security

Do not post Twitch account tokens, client-integrity values, signing certificates, provisioning profiles, device identifiers, raw authenticated requests, or private chat content in public reports.

For ordinary regressions, provide the build identity, reproducible steps and a sanitized diagnostic export. Review screenshots and crash logs separately before sharing. Native diagnostic reports contain bounded runtime and service observations.

For a sensitive issue, ask the maintainer for a private reporting route without publishing the sensitive details. If GitHub offers private vulnerability reporting for the repository, use that route.
