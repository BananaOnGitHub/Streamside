# Streamside modular diagnostics: build 19

This is the unsigned device-test candidate from source `f9bcc5867588edd75a53bf48b4eaa9d4b24e1bdc` on
`feat/modular-diagnostic-runtime`, based on `dev/3.1.0`.
Sign/install the IPA using your existing sideloading setup. Packaging and host
validation passed; actual iOS runtime/keyboard/layout/CPU acceptance is pending.

1. Open a stream normally, then open Streamside → Diagnostics → Investigations.
2. Check that RN chat gaps becomes Dormant, then choose Arm.
3. Once Armed, enable the In-chat Capture button and return to the stream.
4. Remain in chat normally. When the gap occurs, tap Capture immediately,
   keeping the stream and keyboard in their current state.
5. After capture completes, return to Investigations to Copy or Export Capture.
6. Stop collection when finished. Backgrounding also requests Stop; the frozen
   report remains available. Restarting Twitch clears in-memory reports.

Check late arm without chat reopening, original/own messages and rewards,
long sessions, rapid/repeated captures, Stop, background/foreground, rotation,
accessibility, capture-button hit testing, keyboard focus and scroll position.
If Unsupported persists or a command times out, retain the available report and
record the exact state; relaunch to reset the session. Do not treat missing
observations as proof that Twitch dropped a message.

The current adapter reports unavailable filtering/deduplication decisions,
confirmed reconciliation, actual reward renderer/catalog state, estimated
sizes and native row geometry. Coverage is explicit and incomplete.
